# VRChat との連携

このガイドでは、Galbi SDK を使用して VRChat ワールドと 3D モデルを同期する方法について説明します。

### ワールドにアクセス

デバッグ用のワールドを作成しています。
このワールドはGalbi SDKと連携をしてワールドの確認ができます。

- ワールド名: [Project Galbi](https://vrchat.com/home/launch?worldId=wrld_068ed758-68b1-40bc-b647-f54c3b3d92fc)
- URL: https://vrchat.com/home/launch?worldId=wrld_068ed758-68b1-40bc-b647-f54c3b3d92fc


### URLを読み込み

ワールドにアクセスをしたら、URLを読み込みます。
