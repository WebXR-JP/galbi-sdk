# ワールドの生成


### エディターの起動


さきほどフォークをしたプロジェクトのぺージから「EDITOR」をクリックすることで、

エディターを起動することができます。

![alt text](/captures/030.png)



### テンプレートプロジェクトを起動
このプロジェクトでは、プロジェクトの作成する方法をご紹介します。

「Launch」ボタンをクリックしてください。 

![alt text](/captures/12.png)


### プロジェクトの起動

プロジェクトを起動をすると、このような画面が表示されます。
ここから URL を生成して同期の準備を進めてください。

![alt text](/captures/13.png)

### URLを取得

URLを生成をクリックしてください。

![alt text](/captures/14.png)


### 同期について

同期の方法は2つあります。


#### 1.手動同期
「同期する」ボタンを押してください。
そうすることで現在のシーンがURLに同期されます。
![alt text](/captures/15.png)


#### 2.自動同期

自動同期を利用することで、シーンの変更を自動的にURLに反映することができます。
![alt text](/captures/16.png)


そうしたらURLをコピーしてください。

次に、VRChat側で読み込む方法をご紹介します。
