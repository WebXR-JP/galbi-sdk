# Galbi SDK の概要

---

カルビは日本語と韓国語でばら肉を指します。
このSDKを作成する際、韓国語を勉強しながら焼き肉を食べたいと思ったので、カルビという名前を付けました。

![Galbi SDK](/ja/about.png)


## 概要

Galbi SDKは、WebGL (PlayCanvas) で開発した3DモデルデータをVRChatに持ち込むための仕組みです。複数のユーザーがVRChatのワールド内で同時に作業し、リアルタイムでデバッグが可能です。具体的には、ワールドのアイデアを出し合ったり、モデルデータを変更した際に、アップロードせずにそのままワールドの見え方を確認できます。

また、成果物に関してもglTF形式で出力ができるので、UnityやBlenderなどのソフトウェアで最終調整をして、VRChatにアップロードすることができます。
