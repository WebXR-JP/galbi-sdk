# 공동 편집자 추가

공동 편집자 추가


### 초대 생성

프로젝트 설정에서 `EDIT`을 클릭하세요.

![alt text](/captures/42.png)

### 사용자 이름 입력

초대할 사람의 PlayCanvas 사용자 이름을 입력하고 `SEND`를 클릭하세요.
![alt text](/captures/43.png)


### 권한 변경

공동 편집을 위해 상대방의 권한을 `WRITE`로 변경하세요.


![alt text](/captures/44.png)

> [!NOTE]
> **권한 종류**
> - "Read" - 보기만 가능
> - "Write" - 보기와 편집 가능 ← 일반적으로 이것을 선택
> - "Admin" - 보기, 편집, 프로젝트 자체 삭제 가능

### 공동 편집 화면

여러 사람이 하나의 프로젝트에서 공동 편집을 할 때, 각자가 수행한 변경 사항이 실시간으로 반영됩니다.

![alt text](/captures/45.png)

친구들과 함께 개발하면 즐겁습니다.
