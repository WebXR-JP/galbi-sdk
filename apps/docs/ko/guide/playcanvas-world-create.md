# 월드 생성


### 에디터 실행


방금 포크한 프로젝트 페이지에서 "EDITOR"를 클릭하여

에디터를 실행할 수 있습니다.

![alt text](/captures/030.png)



### 템플릿 프로젝트 실행
이 프로젝트에서는 프로젝트를 만드는 방법을 소개합니다.

"Launch" 버튼을 클릭하세요.

![alt text](/captures/12.png)


### 프로젝트 시작

프로젝트를 시작하면 이러한 화면이 표시됩니다.
여기서 URL을 생성해 동기화 준비를 진행하세요.

![alt text](/captures/13.png)

### URL 가져오기

"URL 생성"을 클릭하세요.

![alt text](/captures/14.png)


### 동기화 정보

동기화하는 방법에는 두 가지가 있습니다.


#### 1. 수동 동기화
"동기화" 버튼을 클릭하세요.
이렇게 하면 현재 씬이 URL에 동기화됩니다.
![alt text](/captures/15.png)


#### 2. 자동 동기화

자동 동기화를 사용하면 씬의 변경 사항이 자동으로 URL에 반영됩니다.
![alt text](/captures/16.png)


그런 다음 URL을 복사하세요.

다음으로, VRChat에서 로드하는 방법을 소개하겠습니다.
