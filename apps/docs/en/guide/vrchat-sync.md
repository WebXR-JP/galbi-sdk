# Integration with VRChat

This guide explains how to synchronize VRChat worlds and 3D models using Galbi SDK.

### Accessing the World

We have created a world for debugging purposes.
This world can be used to check your world in conjunction with Galbi SDK.

- World Name: [Project Galbi](https://vrchat.com/home/launch?worldId=wrld_068ed758-68b1-40bc-b647-f54c3b3d92fc)
- URL: https://vrchat.com/home/launch?worldId=wrld_068ed758-68b1-40bc-b647-f54c3b3d92fc
