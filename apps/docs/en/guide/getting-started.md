# Overview of Galbi SDK

---

"Galbi" means "rib meat" in Japanese and Korean.
I named it Galbi because I was studying Korean and wanted to eat Korean BBQ while making this SDK.

![Galbi SDK](/en/about.png)


## Overview

Galbi SDK is a system that allows you to bring 3D model data developed in WebGL (PlayCanvas) into VRChat. Multiple users can work simultaneously within a VRChat world and debug the world in real-time. Specifically, you can brainstorm world ideas and check how the world looks after making model data changes without having to upload them.

Additionally, the output can be exported in glTF format, allowing you to make final adjustments in software like Unity or Blender before uploading to VRChat.
