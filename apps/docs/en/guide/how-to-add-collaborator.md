# Adding Collaborators

Adding collaborators


### Creating an Invitation

From the project settings, click `EDIT`.

![alt text](/captures/42.png)

### Enter Username

Enter the PlayCanvas username of the person you want to invite, then click `SEND`.
![alt text](/captures/43.png)


### Changing Permissions

For collaborative editing, change the person's permission to `WRITE`.


![alt text](/captures/44.png)

> [!NOTE]
> **Permission Types**
> - "Read" - View only
> - "Write" - Can view and edit ← Generally select this
> - "Admin" - Can view, edit, and delete the project itself


---


### Collaborative Editing Screen

When multiple people join one project for collaborative editing, changes made by each person are reflected in real-time.
