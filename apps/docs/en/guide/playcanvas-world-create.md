# Creating a World


### Launching the Editor


From the project page you just forked, click "EDITOR" to

launch the editor.

![alt text](/captures/030.png)



### Launch Template Project
In this project, we will introduce how to create a project.

Click the "Launch" button.

![alt text](/captures/12.png)


### Starting the Project

When you start the project, you'll see a screen like this.
From here, generate a URL to prepare synchronization.

![alt text](/captures/13.png)

### Get URL

Click "Generate URL".

![alt text](/captures/14.png)


### About Synchronization

There are two ways to synchronize.


#### 1. Manual Synchronization
Click the "Sync" button.
This will synchronize the current scene to the URL.
![alt text](/captures/15.png)


#### 2. Auto Synchronization

Using auto-sync, you can automatically reflect scene changes to the URL.
![alt text](/captures/16.png)


Then copy the URL.

Next, we'll show you how to load it in VRChat.
